# CS-330-Computer-Graphic-and-Visualization

Working through this course and on this project has reinforces some of my skills when designing modular and reusable code. From the start, I understood that the scene to be replicated would contain multiple object that I would make many tweaks to. I factored this in by designating a function for how each object gets rendered to the scene and having an overall function to render the whole scene. This choice allowed me to locate and make tweaks to the code where needed, or reuse code from one object to create another. For example, I had multiple mug objects with varying positions in the scene and I simply repositioned them and made the necessary changes to their functions. I think the most useful tactic was designing the code to be modular from the start, setting a good foundation as I learned about transformations, texturing, and shaders which can be carried over in my future work. Additionally, working with OpenGL and other graphics libraries has deepened my knowledge in computer graphics and visualizations, which has given me more confidence skills going forward.
